확인 중
검토할 분석 결과를 끌어다 놓으세요 PDF, HWPX, Word, Excel, CSV, 텍스트를 읽을 수 있어요.
검토 자료
12턴 회의
1라운드 첫 의견2라운드 반론과 보완최종 반론결론
아직 회의 전이에요자료를 올리고 '회의 시작'을 누르면 사회자가 회의를 열어요.
검토결과가 아직 없어요12번째 턴에서 사회자가 정리해 드려요.
각자의 메모는 암호화되어 있어요회의실도 열어 볼 수 없어요. 회의가 끝나면 각 에이전트에게 공개를 부탁할 수 있어요.

설정

키는 이 브라우저에만 보관하고, 요청할 때 이 사이트 서버를 거쳐 OpenRouter로만 보내요. 서버에 저장하지 않아요. 공용 PC에서는 저장하지 마세요. 키는 openrouter.ai의 Keys 메뉴에서 만들 수 있어요.

본인 API 키를 넣으면 암호 없이 쓸 수 있어요.
